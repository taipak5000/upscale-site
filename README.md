# 画像サイズ拡大ツール

小さすぎて使えない画像を、倍率・ピクセル数・印刷サイズ（mm × dpi）を指定して大きくするWebツールです。

- 処理はすべてブラウザ内で行い、画像はどこにも送信しません
- 拡大方式は「くっきり（Lanczos3）」「なめらか（バイキュービック）」「ドット絵（ニアレストネイバー）」から選べます
- 縦横比が合わないときは、余白を付ける・はみ出しを切る・引き伸ばすの3通り
- PNG / JPEG / WebP で保存。PNG・JPEGにはdpi情報も書き込めます
- 複数枚をまとめて変換し、ZIPで保存できます
- Service Worker（stale-while-revalidate）で、一度開けばオフラインでも動きます

HTML / CSS / JavaScript だけで動くので、GitHub Pages にそのまま置けます。
